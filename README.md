# 기쁨 생일 기록 · Khushali's 22nd Birthday Surprise 🎁

ખુશાલી માટે બનાવેલી બર્થડે સરપ્રાઈઝ વેબસાઈટ, બનાવનાર: દાતી (Alien 👽)

## Flow
Shayari intro → Gift box → 4 Balloons → Cake (candles) → Our story (4 chapters) → Voice note (jo hoy to) → Photo cards → Movie ticket + Trailer → Letter → One last gift (collage) → Finale (K-drama secret + wish)

## Files
- `index.html`, `style.css`, `script.js` : website
- `images/` : photos (m01–m12 cards, c1–c7 collage)
- `videos/trailer.mp4` : badha videos mathi banavelu ~1.5 minute nu movie trailer (Duniyaa music sathe)
- `audio/song.mp3` : background music (Sang Rahiyo)
- `audio/voice.mp3` : (optional) tamaro voice note. Aa file mukso to j "voice" step dekhase, nahi to aape-aape skip thai jase.

## Text badalvo hoy to
`script.js` ma upar `CONTENT` block ma balloon lines, photo captions ane letter chhe.
